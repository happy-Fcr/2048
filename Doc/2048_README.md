# GD32F470 2048 游戏

本工程运行于 GD32F470ZG，使用 LCD 显示 2048 棋盘，使用四个独立按键控制上下左右移动。

## 功能

- 开始菜单、难度选择和 Top 10 排行榜。
- Easy、Normal、Hard 三种模式，控制生成 2 和 4 的概率。
- 达到 2048 后显示胜利界面，无法继续移动时显示游戏结束界面。
- 排行榜保存到内部 Flash 最后一个 4 KiB 页面，并通过魔数、版本号、校验和及降序检查验证。

## 按键

| 引脚 | 功能 |
| --- | --- |
| GPIOG.9 | 上 |
| GPIOB.15 | 下 |
| GPIOA.0 | 左 |
| GPIOB.2 | 右 |

按键采用下拉输入，按下时为高电平。
